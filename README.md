
# House Price Prediction Using Machine Learning

## Project Overview
This project predicts house prices using
Machine Learning techniques.

## Objective
To estimate house prices based on property
features such as location, area, BHK,
bathrooms and amenities.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Random Forest Regression
- Power BI

## Machine Learning Algorithm
Random Forest Regression

## Project Steps
1. Dataset Exploration
2. Data Cleaning
3. Data Preprocessing
4. Exploratory Data Analysis
5. Train-Test Split
6. Model Training
7. House Price Prediction
8. Model Evaluation
9. Power BI Visualization

## Model Evaluation
- MAE
- MSE
- RMSE
- R2 Score

## Conclusion
The project estimates house prices using
a trained Random Forest Regression model.
